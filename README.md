# Torchlight Overlay

Локальные оверлеи **Tartarus, Vorax и Arcana** в одной программе для Windows x64. Программа читает экран и рекомендует действия; ходы делает игрок. Установленные оверлеи других авторов, Node.js и Rust для запуска EXE не нужны.

**[1.3.15 preview — Portable и Setup EXE](https://github.com/milkmiraclework-alt/torchlight-overlay-optimized/releases/tag/v1.3.15)**. [Стабильные выпуски](https://github.com/milkmiraclework-alt/torchlight-overlay-optimized/releases/latest) обновляются отдельно.

## Изменения 1.3.15

- Автоматическое восстановление позиции из журнала и прочитанных данных после перезапуска при совпадении прохода и всех игровых действий. На диск сохраняются данные поля, без изображений и сырых строк журнала.
- Исправлены повторный учёт собранных клеток, забывание изменений скрытой части пути и потеря выгодных цепочек улучшений перед завершением.
- Для подтверждённых обычного маршрута и маршрута с радужными сундуками подключено оригинальное ядро Timer. Остальные три типа используют наш расчёт с учётом будущих клеток и свободных мест для сундуков.
- Окно копирования учитывает фактически сыгранную карту, даже если игрок выбрал другой ход. После бесплатного кубика новая грань читается отдельно; закрытая грань вызывает автоматическое ожидание. Повторное чтение не расходует карту ещё раз.
- Точный расчёт концовки не предлагает улучшение без подходящего сундука ради сброса лимита перебросов. Полезные цепочки с зелёного сундука сохраняются. Наведение мыши и свечение карт не перезапускают чтение.
- Пройдены 70 групп проверок исходников и 15 групп проверок упакованных EXE, включая захват тестового окна, запуск Portable дважды и остановку дочерних процессов.

## Распознавание и общие оптимизации

- Arcana использует обученные распознаватели руки и кубика Timer с его разрешения. Число карт проверяется по полному счётчику `x/10`, точки обычных кубиков — дополнительно по текстурам. Исправлена найденная путаница «1»/«3» после масштабирования захвата.
- Позиция отслеживается по событиям игры, тип и длина пути определяются по наблюдаемым паттернам. До надёжного определения доступны советы по видимым клеткам; фиктивная длина 80 не подставляется. Метки показывают фактические номера при известной позиции или расстояние от `YOU`.
- Исправлено чтение жизни, клеток `+1`/`+2`/`+3`, тройного вопроса, карт на поле и радужных сундуков. Временно закрытый сундук сохраняется для отображения; недостоверное состояние блокирует совет. Подтверждённый сбор из журнала учитывается до завершения анимации награды.
- Прочитанные клетки сохраняются между ходами. Анимация фона не сбрасывает ручное исправление; настоящий ход делает прежнее исправление недействительным. Старый кадр после нового события игры не используется для совета.
- Окна выбора читаются отдельно от размытого фона. Закрывающееся окно вызывает автоматическое ожидание и ограниченный повтор чтения.
- Добавлены метки над клетками: текущее положение, неизвестные клетки и цель совета. Они пропускают клики и закрываются при отключении захвата или смене режима.
- Vorax записывает локальный журнал прочитанных полей, советов, оценок и подтверждённых результатов для анализа. Неизвестный фактически сыгранный ход остаётся неизвестным; совет не записывается как действие игрока. Запись асинхронная, объём ограничен. Правила и стратегия Vorax в этой версии не менялись.

Неверных подтверждённых позиции, жизни и количества сундуков не найдено; ручных проверок на этой записи не потребовалось. Это не полная разметка всех карт и типов клеток.

[Определение маршрута](tools/results/arcana-route.json) проверяется на 2000 наблюдений пяти типов полей генератора Timer. Неоднозначный тип не выдаётся за подтверждённый. Проверки генератора не доказывают универсальное распознавание серверных карт.

Все проверки используют сохранённые кадры, симуляции и собственные тестовые окна. Настоящая игра пользователя не захватывается, ввод в неё не отправляется. Отчёты [общих проверок](tools/results/checks.json), [проверок EXE](tools/results/packaged-checks.json) и [проверки выпуска](tools/results/release-audit.json) фиксируют конкретную версию и состав проверок. Проверки не доказывают универсальное распознавание всех серверных полей; игровой доход не измерялся.

## Запуск

Закройте прежние оверлеи через трей и запустите Portable либо установите Setup. В настройках разрешите захват. В игре включите **Esc → Account Related → Enable Log**, затем выйдите из аккаунта и войдите снова. Для Tartarus укажите Speed-up как в игре; для Vorax — уровень Intern Shelley.

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+P или Ctrl+Alt+X | Прочитать текущий экран |
| Ctrl+Alt+O или Ctrl+Alt+V | Показать/скрыть оверлей |
| Ctrl+Alt+A | Исправить поле Tartarus |
| Ctrl+Alt+I | Проверить инструменты Tartarus |
| Ctrl+Alt+Q | Закрыть программу |

Профиль: `%APPDATA%\Torchlight Overlay`. Журналы Vorax: `logs\vorax` внутри профиля; анализ: `node tools/vorax-journal-report.js --dir <папка журналов>`.

Советы и распознавание работают локально. Снимки не сохраняются и не отправляются. Обращения к GitHub используются для обновлений: первая проверка через 45 секунд, далее раз в 6 часов. Стабильное обновление загружается, когда программа не занята мини-игрой; установка — по команде **Restart and install**. Preview не заменяет стабильный канал автоматически. Проверяются размер и SHA256, профиль сохраняется.

## Совместимость и сборка

Windows x64, Intel/AMD; проверено на Windows 11. Нужны Windows Graphics Capture/Direct3D 11, оконный режим или окно без рамки, английский интерфейс игры. Для Vorax нужен Windows OCR, предпочтительно English (United States). Поддержка любого разрешения, HDR, произвольного масштаба интерфейса или ARM не гарантируется.

Для сборки нужны Node.js 22.12+ и npm. Готовые ядра сопровождаются отпечатками исходников.

```powershell
.\Build-Standalone.cmd
.\Start-Overlay.cmd
```

Результат: `desktop/dist/builds/1.3.15/`. Для изменения нативных ядер нужны Rust и Windows build tools; скрипты сборки и проверки находятся в `tools/`.
