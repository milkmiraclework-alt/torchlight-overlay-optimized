# Torchlight Overlay

Одна программа с оверлеями **Tartarus и Vorax** для Torchlight: Infinite.

Интерфейс Tartarus использует Electron; расчёты — Rust/WASM. Vorax работает
нативным управляемым процессом Rust. Board остаётся отдельным окном ручного
исправления поля; повторный запуск приложения открывает общие настройки.
Полностью нативная оболочка без Electron пока не реализована.

- Один запуск, значок в трее и окно настроек. Автоматическое переключение по журналу игры; режим можно выбрать вручную.
- Tartarus: ускоренное чтение, расчёты на Rust/WASM, полный бюджет Monte Carlo, кэш и предрасчёт следующих ходов. Цель — ожидаемое число Rainbow, максимум 10.
- Vorax: нативный захват, Windows OCR, исправленный читатель smart.3 и Smart-советник. Цель — итоговая активность с ограничением 840 000.
- Потоки подбираются под процессор. Vorax по умолчанию получает число доступных логических процессоров минус один, минимум один; настройка `0` означает автоматический режим.
- При смене режима неактивный расчётчик останавливается. Выключение захвата и выход завершают управляемый процесс Vorax и освобождают воркеры Tartarus.
- Убраны веб-симулятор и руководства из сборки, запись скриншотов/партий, отправка отчётов, отдельные трей и автообновляторы. При раннем неудачном чтении Tartarus делает до двух дополнительных снимков; новый ход или выход отменяет их.

Первый ещё не готовый кадр также получает ограниченный повтор. OCR начинает
готовиться уже на событии открытия цели или инструментов. Для явно указанного
экрана инструментов не запускается долгий поиск обычной тюремной доски;
запоздалое подключение захвата не сбрасывает новое.

В 1.0.2 нераспознанный выбор инструмента больше не заменяется рекомендованным.
Похожие значки с близкими оценками считаются сомнительными; несколько образцов
одного инструмента не создают ложную неоднозначность. Пока набор не уточнён,
советы по нему не выдаются. Событие нового предложения учитывается даже при
неудачном снимке. Для ручной сверки нажмите Instruments в оверлее или Ctrl+Alt+I:
список открывается поверх Board на экране игры, включая повторное открытие
после закрытия. Выберите инструменты, затем These are right. Подтверждённый набор сохраняется до нового
выбора или ручного изменения; шумные кадры не сбрасывают подтверждение.

Отдельная проверка local.30/local.31 на 56 одинаковых позициях с бюджетом 400
дала одинаковые рекомендации: 18 Consume, 24 Replace, 3 Hunt и 11 End.
Формула обычного Consume не менялась. Это ограниченный сравнительный тест,
не гарантия для всех позиций: [отчёт](tools/results/consume-local31-audit.json).
Присланная красная карта, не читавшаяся smart.2, распознана читателем общей
программы: [сравнение на одном кадре](tools/results/vorax-card-contrast.json).

## Запуск

Скачайте **Portable EXE** или **Setup EXE** из [Releases](https://github.com/milkmiraclework-alt/torchlight-overlay-optimized/releases/latest). Node.js, Rust и прежние оверлеи для запуска не нужны.

С **1.0.3** оба EXE проверяют новые стабильные версии в нашем GitHub Releases:
через 45 секунд после запуска, затем раз в 6 часов. Загрузка начинается, когда
оверлей не занят мини-игрой, и ограничена примерно 2 МБ/с. В настройках есть
Check now, Download update и переключатель автоматической проверки/загрузки.
После загрузки нажмите Restart and install в настройках, трее или оверлее.
Программа сама посреди забега не перезапускается. Setup обновляет установленную
копию; Portable заменяет свой исходный файл, сохраняя путь и ярлыки. Проверяются
размер и SHA256 GitHub-артефакта; профиль, кэш и подтверждения не заменяются.
Без Интернета советы продолжают работать. Обращения к GitHub нужны только для
обновлений; снимки и игровые данные туда не отправляются. Версии до 1.0.3 нужно
один раз обновить вручную. Распакованные сборки разработчика не заменяются.

Закройте прежние оверлеи через их трей и запустите новую программу. В настройках включите захват. В игре включите Esc → Account Related → Enable Log, затем выйдите из аккаунта и войдите снова. Для Tartarus укажите, включён ли Speed-up в игре; для Vorax — уровень Intern Shelley.

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+P или Ctrl+Alt+X | Прочитать текущий экран |
| Ctrl+Alt+O или Ctrl+Alt+V | Показать/скрыть оверлей |
| Ctrl+Alt+A | Исправить поле Tartarus |
| Ctrl+Alt+I | Открыть инструменты Tartarus на экране игры |
| Ctrl+Alt+Q | Закрыть программу |

Программа только читает экран и рекомендует действия. Все ходы делает игрок.
Скриншоты не записываются и не отправляются. Начиная с 1.0.1 общий профиль
находится в `%APPDATA%\Torchlight Overlay`, отдельно от старого Tartarus.
Настройки импортируются один раз. Подтверждения и кэш переносятся, если старый
оверлей закрыт перед первым запуском; работающая база не копируется, новые
данные не перезаписываются. Уровень Shelley импортируется из прежнего Vorax.

## Совместимость

Сборка Windows x64 для Intel и AMD; проверена на Windows 11. Нужны доступный Windows Graphics Capture/Direct3D 11, оконный режим или окно без рамки и английский интерфейс игры. Vorax использует установленный распознаватель Windows OCR; предпочтителен English (United States).

Чтение масштабируется по размеру игрового окна. Tartarus проверяется на 1080p, 1440p и 4K; Vorax — на нескольких размерах в исходных тестах и на сохранённых кадрах. Работа на любом нестандартном разрешении, интерфейсном масштабе, HDR, ARM или 32-битной Windows не гарантируется. Общая программа не означает универсального прироста FPS или результата мини-игр.

## Сборка и проверки

Для сборки EXE нужны Node.js 22.12+ и npm. Готовые ядра Rust/WASM и нативный Vorax включены с отпечатками исходников:

```powershell
.\Build-Standalone.cmd
.\Start-Overlay.cmd
```

Результат: `desktop/dist/builds/1.0.3/`. Изменения Vorax требуют Rust и Windows build tools: `powershell -File tools/build-vorax-backend.ps1`. Изменения ядра Tartarus: `powershell -File tools/build-rust-solver.ps1`. Скрипты проверяют соответствие бинарников исходникам.

```powershell
node tools/unified-runtime-check.js
node tools/picture-retry-check.js
node tools/rust-solver-check.js --wasm
node tools/suite-overlay-check.js
node tools/standalone-smoke.js
```

Проверки используют симуляции, сохранённые кадры и собственное тестовое окно. Они не захватывают настоящую игру и не отправляют в неё ввод.

## Исходники и авторство

Tartarus основан на [blahdot3h/tartarus-simulator](https://github.com/blahdot3h/tartarus-simulator), CoffeeBns, правила `308b947`, локальные оптимизации до local.31. Vorax основан на [DinoRaos/vorax-rs](https://github.com/DinoRaos/vorax-rs), `f117a01`, и [tidewarden/tli-vorax-simulator](https://github.com/tidewarden/tli-vorax-simulator), `7881e7f`; Smart и исправления читателя сохранены. Авторство и MIT-лицензия Vorax: [vorax/LICENSE](vorax/LICENSE). Лицензии Electron, OCR и зависимостей включаются в сборку. Этот репозиторий — отдельная интеграция, не официальный релиз авторов.
